# Преводач BG — Android проект с Google Cloud Translation и облачно компилиране

Проектът съдържа Android приложение (Kotlin + WebView) и GitHub Actions workflow за компилиране на debug APK без локален компютър. Преводът използва официалния Google Cloud Translation Basic API (v2). Изходният език не се изпраща в заявката, така че Google го разпознава автоматично; целевият език се избира в приложението.

## 1. Създай Google Cloud проект и API ключ

1. Отвори https://console.cloud.google.com/ от телефона и създай нов проект.
2. Настрой Billing за проекта, ако Google го изисква за активиране на Cloud Translation.
3. Отвори APIs & Services → Library и активирай **Cloud Translation API**.
4. Отвори APIs & Services → Credentials → Create credentials → API key.
5. Отвори ключа и ограничи **API restrictions** до Cloud Translation API. Не публикувай ключа и не го качвай в GitHub. В приложението ключът се въвежда в полето при употреба; не е вграден в APK.
6. Отвори Cloud Translation Quotas и задай разумен лимит на заявките/знаците на ден и на минута. По подразбиране Google отбелязва, че дневният брой знаци може да е неограничен, затова не пропускай тази стъпка.
7. В Billing настрой бюджета/известията. Имай предвид: обикновените budget alerts са известия, не твърд лимит. Ако в конзолата е наличен Spend cap за подходяща услуга, прегледай ограниченията му; той не гарантира нулево превишение, защото отчитането има закъснение.

Официални страници:
- Цени: https://cloud.google.com/products/translate/pricing
- Настройка: https://docs.cloud.google.com/translate/docs/setup
- Квоти: https://docs.cloud.google.com/translate/quotas
- API за превод: https://docs.cloud.google.com/translate/docs/translate-text

## 2. Предпазване от неочаквани разходи

- Ценовата страница в момента посочва месечен кредит/безплатен обем за първите 500 000 знака при стандартния модел NMT; условията и наличността могат да се променят. Над безплатния обем може да има такса. Провери актуалната ценова страница в собствения си проект.
- Приложението спира локалния превод при 450 000 входни знака за текущия календарен месец на това устройство.
- Този локален лимит НЕ вижда заявки от други устройства, други приложения или други потребители, използващи същия API проект/ключ. Затова е задължително да зададеш квоти в Google Cloud.
- Въвеждай ключа само в приложението на собственото си устройство. Не го изпращай в чат и не го слагай в публично хранилище.

## 3. Компилиране само с Android телефон

1. Влез в https://github.com/ и създай акаунт, ако нямаш.
2. Създай хранилище `PrevodachBG`. За най-простия първи опит може да е public, но не качвай API ключ, лични книги или други чувствителни файлове.
3. Качи съдържанието на тази папка, включително `.github/workflows/build-apk.yml`. Ако мобилният браузър не показва скритата папка `.github`, включи Desktop site.
4. Отвори Actions → Build PrevodachBG APK → Run workflow.
5. След успешно изпълнение изтегли artifact `PrevodachBG-debug-apk` и разархивирай ZIP файла. В него трябва да е `app-debug.apk`.
6. Инсталирай APK, отвори го, постави API ключа и пробвай кратък TXT файл.

## 4. Ограничения на текущата версия

- Това е изходен проект; APK не е потвърдено компилиран или тестван на физическо устройство.
- TXT, DOCX и PDF с текстов слой се обработват чрез извличане на текст. Сканирани PDF файлове изискват OCR, който още не е включен.
- Изходният файл е нов документ; не се запазва напълно оригиналното оформление, изображенията, таблиците и бележките. DOCX/TXT са най-подходящи за първите тестове.
- Преводът се изпраща изречение по изречение. Това позволява запазване на напредъка, но може да загуби контекст между изреченията и да отнеме време за голяма книга.
- Не използвай единственото копие на книгата. След първия тест провери пауза, затваряне/повторно отваряне и продължаване.
